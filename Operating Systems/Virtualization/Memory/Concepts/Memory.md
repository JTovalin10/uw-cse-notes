# CSE451: Memory

## What Is It

OSTEP: *Instructions lie in memory; the data that the running program reads and writes sits in memory as well.*

This includes:
- The program itself (code and data).
- The **Virtual Machine** abstraction the OS provides on top of physical memory, so each process perceives its own private memory space rather than directly seeing physical RAM.
