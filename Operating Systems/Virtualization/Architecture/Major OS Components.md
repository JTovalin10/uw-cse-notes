# CSE451: Major OS Components

The operating system is organized around a set of major components, each responsible for managing a different resource or providing a different abstraction:

- **[[Process|Process]](es)** / **[[Thread|Thread]](s)** — units of execution the OS schedules and isolates from one another.
- **[[Memory]]** — management of physical and virtual memory.
- **[[Operating Systems/Virtualization/Architecture/IO|IO]]** — communication between programs and devices.
- **[[Secondary Storage]]** — persistent storage such as disks.
- **[[File Systems]]** — organization of persistent data into files and directories.
- **[[Operating Systems/Virtualization/Architecture/Protection|Protection]]** — mechanisms that guard resources from unintentional and malicious misuse.
- **[[Operating Systems/Virtualization/Architecture/Command Interpreter (shell)|Command Interpreter (shell)]]** — the user-facing interface for launching and controlling programs.
- **GUI** — graphical user interface components.
- **Networking** — communication between machines.
